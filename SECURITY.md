# Security and privacy

This Space is configured as public by the owner. Anyone can access its application and API; do not process confidential research without appropriate access controls. No HF access token is required by the running application. Never commit tokens to the repository. Input text and generated files may reside temporarily in server memory or `/tmp` until collection or restart. This release does not implement account-based isolation or persistent user history. Do not interpret writing-pattern scores as AI-authorship determinations.
